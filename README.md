# DevConf 2026

## Project Overview

A responsive conference website designed for DevConf 2026. The project features a clean and modern event-focused layout to present conference information in an organized and user-friendly way.

## Technologies Used

* HTML5
* CSS3

## Main Features

* Responsive conference website
* Clean and modern user interface
* Conference information sections
* Organized event-focused layout
* Mobile-friendly design

## Dependencies

This project does not require any external dependencies. It is built using HTML5 and CSS3.

## How to Run Locally

1. Clone the repository:

   ```bash
   git clone https://github.com/ijannathalima-ux/assignment-01-github.git
   ```

2. Open the project folder.

3. Open `index.html` in your browser.
